I build **[TrayTrigger](https://github.com/stephenh678/TrayTrigger)**, launch control for PC games on Windows.

Per-game Windows tuning and launch automation: performance profiles, your own pre-launch and post-exit scripts, launch arguments, and launchers that close themselves. Everything reverts when the game exits. Steam, GOG, Epic, EA, Ubisoft, Xbox. Lives in your tray.

- **[Download the latest release](https://github.com/stephenh678/TrayTrigger/releases/latest)**: installer or portable ZIP, no telemetry, no account.
- **[Wiki](https://github.com/stephenh678/TrayTrigger/wiki)**: every tweak explained, what it changes, and how it's reverted.
- **[TrayTrigger-Scripts](https://github.com/stephenh678/TrayTrigger-Scripts)**: the community script catalog. Pull requests welcome.
- **[Discussions](https://github.com/stephenh678/TrayTrigger/discussions)**: questions, ideas, and the "which launcher next?" poll.

Stack: C#, WPF, .NET 10, PowerShell.

I build **[TrayTrigger](https://github.com/stephenh678/TrayTrigger)**, an open-source game launcher for Windows. Launch from the tray, and let Windows adapt to the game.

Steam, Epic, GOG, Xbox, Battle.net and more in one tray menu. Each game starts with its own HDR, CPU cores, power plan, DLSS and scripts, and those settings are put back when you quit.

- **[Download the latest release](https://github.com/stephenh678/TrayTrigger/releases/latest)**: installer or portable ZIP, no telemetry, no account.
- **[Wiki](https://github.com/stephenh678/TrayTrigger/wiki)**: every setting explained, from launching a game to what gets put back.
- **[TrayTrigger-Scripts](https://github.com/stephenh678/TrayTrigger-Scripts)**: the community script catalog. Pull requests welcome.
- **[Discussions](https://github.com/stephenh678/TrayTrigger/discussions)**: questions, ideas, and the "which launcher next?" poll.

Stack: C#, WPF, .NET 10, PowerShell.
